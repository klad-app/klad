# Security

klad opens `.klad` folders, pictures and fonts that may come from anyone, and runs agents' commands on them. A file that crashes it, reads or writes outside the drawing, or runs code is a security problem.

## Reporting

Please report privately through GitHub's "Report a vulnerability" on the repository's Security tab, not in a public issue. Include the version (`klad --version`), your OS, and the smallest file or command that shows the problem.

We aim to answer within a week, agree on a fix and a date with you, and credit you in the release notes unless you would rather not be named.

## Supported versions

Only the latest release and `main` get fixes while the project is below 1.0.
